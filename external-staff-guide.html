1️⃣ การลงทะเบียน

ขั้นตอนการลงทะเบียนครั้งแรก

ขั้นตอนที่ 1: เข้าถึงลิ้งค์ลงทะเบียน

ติดต่อสำนักงานสถาบันการศึกษา เพื่อขอลิ้งค์สำหรับลงทะเบียน

ลิ้งค์จะอยู่ในรูปแบบ: https://script.google.com/...?page=ext_staff

ขั้นตอนที่ 2: คลิกลิ้งค์และเข้าสู่หน้าลงทะเบียน

1. คลิกลิ้งค์ที่ได้รับมา

2. ระบบจะแสดงหน้าลงทะเบียนขึ้นมา

3. คลิกปุ่ม 📝 ลงทะเบียน (หรือ "สมัครสมาชิก")

ขั้นตอนที่ 3: กรอกข้อมูลลงทะเบียน

กรอกข้อมูลในแบบฟอร์ม:

  • อีเมล - ที่อยู่อีเมลที่ใช้งานได้จริง
  • รหัสผ่าน - ตั้งรหัสผ่านที่แข็งแรง (อย่างน้อย 8 ตัวอักษร)
  • ชื่อสถาบัน/หน่วยงาน - ชื่อสำนักงานหรือหน่วยงานของท่าน
  • ชื่อผู้ติดต่อ - ชื่อและนามสกุลของท่าน
ขั้นตอนที่ 4: รอการอนุมัติจาก Admin

✅ หลังจากลงทะเบียนแล้ว

⏳ ระบบจะส่งคำขอไปให้ Admin เพื่อตรวจสอบและอนุมัติ

📧 Admin จะส่งอีเมลแจ้งการอนุมัติและลิ้งค์สำหรับตั้งรหัสผ่านใหม่

⚠️ ข้อควรระวัง
  • ใช้อีเมลที่ถูกต้อง เพราะ Admin จะส่งการแจ้งให้ที่อีเมลนี้
  • หากไม่ได้รับอีเมลการอนุมัติภายใน 2-3 วัน ติดต่อ Admin โดยตรง
  • อีเมลอาจอยู่ในโฟลเดอร์ Spam ให้ตรวจสอบด้วย

2️⃣ การตั้งรหัสผ่าน

หลังจากได้รับการอนุมัติ

ขั้นตอนที่ 1: ตรวจสอบอีเมลการอนุมัติ

Admin จะส่งอีเมลมาพร้อมกับ:

  • ข้อความแจ้งว่าการลงทะเบียนอนุมัติแล้ว
  • ลิ้งค์สำหรับตั้งรหัสผ่าน (Password Setup Link)
  • คำแนะนำเพิ่มเติม
ขั้นตอนที่ 2: คลิกลิ้งค์ตั้งรหัสผ่าน

1. เปิดอีเมลและคลิกลิ้งค์ที่ส่งมา

2. ลิ้งค์จะนำพาไปยังหน้าตั้งรหัสผ่าน

3. กรอกรหัสผ่านใหม่ลงในช่อง "รหัสผ่าน"

ขั้นตอนที่ 3: บันทึกรหัสผ่าน

1. คลิกปุ่ม 💾 บันทึกรหัสผ่าน

2. รอข้อความแจ้งความสำเร็จ

3. ระบบจะพาไปยังหน้า Dashboard โดยอัตโนมัติ

💡 เคล็ดลับสำหรับรหัสผ่านที่ปลอดภัย
  • ใช้ตัวอักษร ตัวเลข และสัญลักษณ์ผสมกัน
  • ไม่ใช้วันเดือนปีหรือชื่อเด็กเพศ
  • ความยาวอย่างน้อย 8 ตัวอักษร ยิ่งยาวยิ่งปลอดภัย
  • เก็บรหัสผ่านไว้ที่ปลอดภัย อย่าบอกใครอื่น

3️⃣ การเข้าสู่ระบบ

การเข้าใช้งานระบบประจำวัน

ขั้นตอนที่ 1: เข้าหน้าลงชื่อเข้าใช้

1. ใช้ลิ้งค์เดียวกันที่ได้รับมา หรือ

2. บันทึกลิ้งค์นี้ไว้ในบุ๊กมาร์ก (Bookmark) เพื่อใช้ครั้งต่อไป

ขั้นตอนที่ 2: กรอกข้อมูลเข้าสู่ระบบ

ช่อง "อีเมล" - ระบุอีเมลที่ลงทะเบียน

ช่อง "รหัสผ่าน" - ระบุรหัสผ่านที่ตั้งไว้

☑️ จำรหัสผ่าน - (ทำเครื่องหมาย ถ้าต้องการให้ระบบจำรหัสผ่าน)

ขั้นตอนที่ 3: คลิกปุ่มเข้าสู่ระบบ

คลิกปุ่ม 🔐 เข้าสู่ระบบ

รอสักครู่เพื่อให้ระบบโหลดข้อมูล

✅ เมื่อสำเร็จ จะเข้าไปยัง Dashboard

⚠️ ถ้าลืมรหัสผ่าน

ติดต่อ Admin เพื่อขอตั้งรหัสผ่านใหม่ Admin จะส่งลิ้งค์มาที่อีเมลของท่าน

การดูรายการปัญหา

ขั้นตอนที่ 1: เข้าไปที่แท็บ "📋 รายการปัญหา"

ระบบจะแสดงรายการปัญหาทั้งหมดที่ท่านแจ้งมา

ขั้นตอนที่ 2: ตัวกรองและค้นหา

ท่านสามารถกรองตามสถานะ:

  • 🔴 เปิดอยู่ - ปัญหาที่ยังไม่แก้ไข
  • 🟡 กำลังดำเนินการ - ปัญหาที่อยู่ระหว่างการแก้ไข
  • 🟢 แก้ไขแล้ว - ปัญหาที่แก้ไขเรียบร้อย
  • ⚪ ปิดแล้ว - ปัญหาที่ปิดและเสร็จสิ้น
ขั้นตอนที่ 3: คลิกที่ปัญหาเพื่อดูรายละเอียด

1. คลิกที่เลขปัญหา หรือชื่อปัญหา

2. ระบบจะแสดงรายละเอียดทั้งหมด:

  • เลขอ้างอิง
  • วันที่แจ้ง
  • ประเภทปัญหา
  • รายละเอียด
  • สถานะปัจจุบัน
  • ความคิดเห็นจาก Admin
💡 เคล็ดลับในการติดตาม
  • ตรวจสอบ Dashboard อย่างสม่ำเสมอเพื่อดูสถานะปัญหา
  • ใช้ช่องค้นหาเพื่อค้นหาปัญหาเก่าได้อย่างรวดเร็ว
  • สังเกตจำนวนปัญหาในแต่ละสถานะ

สิ่งที่ท่านสามารถทำได้ในระบบ

  • 📈 จำนวนปัญหาทั้งหมดที่แจ้งมา
  • 📊 สัดส่วนของสถานะปัญหา (เปิด, กำลังดำเนินการ, แก้ไข, ปิด)
  • 📉 ประเภทปัญหาที่พบบ่อยที่สุด
  • 📅 ช่องทางติดต่อที่ใช้บ่อย
🔍 ค้นหาปัญหา

ค้นหาด้วยวิธีต่างๆ:

  • เลขปัญหา เช่น CRM-20260521-100
  • ชื่อผู้แจ้ง
  • ประเภทปัญหา
  • สถานะปัญหา
  • ช่วงเวลา (วันที่แจ้ง)
💬 ดูความคิดเห็นและการตอบกลับ

ในรายละเอียดปัญหา ท่านสามารถ:

  • อ่านความคิดเห็นจาก Admin
  • ติดตามการแก้ไข
  • เห็นวันที่อัปเดตล่าสุด
⚙️ แก้ไขข้อมูลส่วนตัว

ในส่วน "โปรไฟล์" ท่านสามารถ:

  • เปลี่ยนชื่อและข้อมูลติดต่อ
  • อัปเดตอีเมลและเบอร์โทร
  • เปลี่ยนรหัสผ่าน
ℹ️ ข้อมูล

ท่านไม่สามารถแจ้งปัญหาโดยตรงในระบบนี้ ให้ติดต่อสำนักงานสถาบันการศึกษา เพื่อแจ้งปัญหา

6️⃣ คำถามที่พบบ่อย (FAQ)

❓ ใช้เวลานานแค่ไหนในการอนุมัติการลงทะเบียน?
โดยปกติ Admin จะอนุมัติภายใน 1-2 วันทำการ หากยาวกว่านี้ให้ติดต่อสำนักงานสถาบันการศึกษา
❓ ลิ้งค์ตั้งรหัสผ่านหมดอายุหรือไม่?
ใช่ ลิ้งค์ปกติจะใช้ได้เพียง 24 ชั่วโมง หากหมดอายุ ให้ติดต่อ Admin เพื่อขอลิ้งค์ใหม่
❓ ถ้าลืมรหัสผ่านควรทำไง?
ติดต่อ Admin ระบุอีเมลของท่าน Admin จะส่งลิ้งค์สำหรับตั้งรหัสผ่านใหม่
❓ ดูรายการปัญหาเก่าได้อย่างไร?
ไปที่แท็บ "📋 รายการปัญหา" และใช้ช่องค้นหาหรือตัวกรองเพื่อค้นหาปัญหาเก่า สามารถกรองตามวันที่ สถานะ หรือประเภท
❓ สามารถแจ้งปัญหาในระบบนี้ได้หรือไม่?
ไม่ ระบบนี้ใช้เฉพาะการติดตามปัญหาที่แจ้งมาแล้ว สำหรับแจ้งปัญหาใหม่ ให้ติดต่อสำนักงานสถาบันการศึกษาโดยตรง
❓ ทำไมปัญหาของฉันไม่ปรากฏในระบบ?
อาจเป็นเพราะ:
1. ปัญหาอาจไม่ได้ลงทะเบียนในระบบ
2. ระบบอาจยังอัปเดตข้อมูล (รอสักครู่แล้วรีเฟรช)
3. ตรวจสอบอีเมลของท่านว่าถูกต้อง
ติดต่อ Admin หากปัญหายังไม่แก้ไข
❓ สามารถเปลี่ยนข้อมูลของปัญหาได้หรือไม่?
ท่านสามารถดูข้อมูลปัญหาได้เท่านั้น เพื่อแก้ไขข้อมูลให้ติดต่อ Admin
❓ ต้องทำอะไรบ้างหลังจากเปลี่ยนรหัสผ่าน?
หลังจากเปลี่ยนรหัสผ่าน ระบบจะพาไปยัง Dashboard โดยอัตโนมัติ ท่านสามารถเริ่มใช้งานได้ทันที
❓ เชื่อถือได้ไหมกับความปลอดภัยของข้อมูล?
ระบบใช้เทคโนโลยีที่ปลอดภัยจากบริษัท Google เข้ารหัสข้อมูล และมีระบบสำรองข้อมูล

7️⃣ การติดต่อสอบถาม

หากมีปัญหาหรือคำถามเพิ่มเติม

📞 ติดต่อ Admin/สำนักงานสถาบันการศึกษา
  • ระบุเลขปัญหา หรือเลขอ้างอิง (ถ้ามี)
  • อธิบายปัญหาที่พบอย่างชัดเจน
  • รอบเวลาทำการปกติ: จันทร์-ศุกร์ 08:30 - 16:30
📧 สิ่งที่ควรมีเมื่อติดต่อ
  • อีเมลของท่าน
  • ชื่อสถาบัน/หน่วยงาน
  • รายละเอียดปัญหา
  • ลิ้งค์หรือสกรีนชอต (ถ้าเป็นปัญหาทางเทคนิค)
